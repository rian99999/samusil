# 짧은 지시 풀어 읽기 (기본값표)
최종 확인: 2026-11-17 · 다음 확인: 2026-12-17

사장님은 "블로그 하나 써줘", "이거 인스타로" 처럼 짧게 말한다. 본부장은 이 표로 빈칸을 채워 **완전한 지시서**로 바꾼 뒤 `plan.md` 맨 위 "지시 풀이"에 적는다. 표의 근거는 `brand/RIAN.md`·`brand/facts.md`·`knowledge/`이다. [공식 · 이 저장소 규칙 · 2026-11-17]

## 1. 말 → 뜻
| 사장님 말 | 뜻 (기본값) |
|---|---|
| 블로그 / 네이버 | 네이버 블로그 글 1편 (네이버팀) + 사진 자리 표시. 그림 요청이 없으면 디자인팀은 부르지 않는다 |
| 인스타 / 피드 | 인스타 피드 1개 + 카드뉴스 문구 4~6장 (인스타팀) + 카드 시안 (디자인팀) |
| 릴스 | 15~30초 릴스 대본 (인스타팀). 3분 넘기지 않는다 |
| 스레드 | 단독 글 3안 + 타래 1개 (스레드팀) |
| 다 / 전부 / 홍보해줘 | 네이버·인스타·스레드·디자인 전부 |
| 카드뉴스 / 썸네일 / 배너 / 이미지 | 디자인팀 (+ 문구가 없으면 해당 채널팀이 문구 먼저) |
| 브랜드커넥트 / 쇼핑커넥트 / 협찬 / 체험단 | 광고 글 → 표시 문구를 **제목 또는 첫 부분** (`ad-disclosure.md`). 제품 정보는 사장님이 준 것만 |
| 이번 달 / 이벤트 | 기간·혜택 숫자는 지어내지 않고 사장님께 묻는다 |
| 고쳐줘 / 다듬어줘 + 글 | 새로 쓰지 않고 그 글만 고친다(해당 채널팀) |
| 비교해줘 / 조사해줘 | 일반 업무: 표 1개 + 출처 목록. 출처 없는 숫자 금지 |

## 2. 안 적었을 때 기본값
| 항목 | 기본값 |
|---|---|
| 대상 고객 | 나에게 맞는 색을 알고 싶은 서면·전포 근처 고객 (성별·나이 전제 없음) |
| 핵심 메시지 | 진단은 명도·채도·온도로 근거를 보여 준다 (RIAN.md) |
| 사실 | `brand/facts.md` 값만. 없으면 `[확인 필요]` |
| 말투 | RIAN.md 말투. AI 말투 금지 |
| 기한 | 그날 안 |
| 올리기 | **안 올린다.** 원고·시안까지만, 사장님 결재함으로 |
| 결과물 | 채널별 최종 파일 1개씩 + 본부장 보고서 |

## 3. 꼭 물어야 하는 것 (기본값으로 채우면 안 됨)
- 가격·할인·기간·인원 같은 **숫자**가 facts.md 에 없을 때
- 제품 협찬 글인데 **제품 이름·링크**가 없을 때
- 고객 사진·후기·이름을 쓰라고 할 때(동의 여부)
- 지시가 브랜드 규칙과 부딪칠 때(예: "최고"라고 써 줘)
그 밖에는 묻지 말고 기본값으로 진행하고, plan.md 의 "지시 풀이"에 무엇을 기본값으로 채웠는지 적는다.
