# RIAN 브랜드 규칙 (직원용 요약)

출처: RIAN 브랜드 가이드라인 v1.6 (2026.10), RIAN 디자인 시스템. 원문과 다르면 원문이 우선한다.
모든 직원은 글·시안을 만들기 전에 이 파일과 `brand/facts.md`를 읽는다.

## 1. 브랜드 한 줄
- 리안 퍼스널컬러&메이크업: 개인의 고유한 아름다움을 발견하고 전문적으로 완성하는 프리미엄 뷰티 컨설팅 (부산 전포·서면).
- 무드: 전문적인 · 세련된 · 섬세한 · 절제된 · 고급스러운
- 원칙: **브랜드는 물러서고, 고객의 색이 주인공이다.**
- 핵심 가치 3단계(순서 고정): Rediscover 다시 발견하다 → Refine 섬세하게 다듬다 → Reveal 드러내다
- 고객: 성별·연령 제한 없음. **글과 그림에서 특정 성별·나이를 전제하지 않는다.**

## 2. 이름 표기
| 용도 | 표기 |
|---|---|
| 공식 상호(국문) | **리안 퍼스널컬러&메이크업** |
| 공식 상호(영문) | RIAN Personal Color & Makeup (RIAN은 항상 대문자) |
| 약칭 | 리안 — **같은 글에서 전체 상호를 한 번 쓴 뒤에만** |
| 로고 | RIAN (시각 요소로만) |
| 금지 | Rian, R.I.A.N, 리안뷰티, 리안주얼리 |

상호·주소·전화번호는 모든 채널에서 글자 하나까지 같게 쓴다(`brand/facts.md` 값 그대로).

## 3. 슬로건 (표기 고정: 가운뎃점·쉼표·마침표·순서 그대로)
- Rediscover · Refine · Reveal
- 당신 안의 아름다움을 다시 발견하고, 고유한 빛으로 완성하다.
- 나만의 아름다움을 발견하다.
- Reveal the beauty that is uniquely yours.

## 4. 브랜드 스토리 (대표 원문 — 줄바꿈·문장 바꾸지 않음)
> 모든 원석이 저마다 다른 빛을 품고 있듯,
> 모든 사람에게는 자신만의 아름다움이 있습니다.
>
> 리안은 그 아름다움을 발견하고,
> 당신에게 어울리는 컬러와 메이크업으로 섬세하게 다듬어
> 가장 당신다운 빛으로 완성합니다.
>
> 아름다움을 몰랐던 순간에서,
> 자신의 아름다움을 알고 표현하는 순간까지.

- 쓰는 곳: 소개 글, 인스타 하이라이트 소개, 상담 공간 액자. 다른 글에 섞어 고쳐 쓰지 않는다.
- '원석' 비유는 이 글 안에서만. 다른 카피·그림에 보석·원석 이미지 금지(주얼리 업종 오인).

## 5. 말하는 방식
1. **고객은 고칠 대상이 아니다.** '보완', '커버', '단점' 대신 '발견', '정돈', '조화'.
2. **사람마다 답이 다르다.** 모두에게 같은 결과를 약속하지 않는다.
3. **근거로 말하고, 보장하지 않는다.** '예뻐요' 대신 이유(명도·채도·온도).
4. **'빛' 비유는 한 글에 한 번만.** 이모지 ✨💎 금지. (예외: 브랜드 스토리 원문)

**쓸 표현:** 고유한 아름다움 · 나에게 가장 잘 어울리는 · 섬세한 분석 · 개인에게 맞는 조화 · 본래 가진 매력 · 나다운 이미지 · 전문적인 맞춤 컨설팅 · 다시 발견하는 아름다움

**쓰지 않을 표현:** 무조건 예뻐지는 · 누구나 똑같이 아름다워지는 · 단점을 완벽하게 없애는 · 극적인 변신("완전 다른 사람", "환골탈태") · 효과 보장("100% 만족", "실패 없는") · 근거 없는 최상급("부산 1위", "최고", "유일한" — 표시광고법상 과장광고 소지) · 유명인 이름 빌리기("OOO 메이크업 그대로")

| 쓰지 않는 말 | 리안의 말 |
|---|---|
| 새로운 나로 다시 태어나요 | 본래 가진 매력을 다시 발견해요 |
| 이 색은 절대 안 어울려요 | 이 색은 피부를 한 톤 어둡게 보이게 해요. 입술에만 쓰면 괜찮아요 |
| 반짝반짝 빛나는 나를 만나요 ✨ | 오늘 찾은 색은 원래 고객님 거예요 |

단계별 짧은 카피: Rediscover "본래 지닌 아름다움을 다시 발견합니다." / Refine "장점을 조화롭게 정돈합니다." / Reveal "가장 나다운 이미지로."

## 6. 채널별 규칙
| 채널 | 원칙 | 확인 지표 |
|---|---|---|
| 네이버 (플레이스·블로그) | **첫 문장에 지역+업종 단어**(서면·전포·퍼스널컬러·메이크업). 미사여구보다 정보. 메뉴는 목록으로 | 유입 키워드, 조회수, 예약 전환 |
| 네이버 플레이스 소식 | 제목에 정보 하나(시즌, 신규 메뉴, 예약 가능일). 본문 3줄 + 예약 안내 | 소식 조회수, 소식→예약 |
| 인스타그램 피드 | **첫 줄에 질문이나 구체적 상황**(잘려도 궁금하게). 본문 2~3줄, 저장 유도, **해시태그 3~5개** | 저장·공유 수, 프로필 방문 |
| 인스타그램 이름·바이오 | 이름: `RIAN 리안 \| 서면 퍼스널컬러`. 바이오 150자 이내: 무엇·어디·어떻게 예약 | 프로필 방문→링크 클릭 |
| 카카오톡 예약 확정 | 꾸밈 없이 정보만: 일시·위치·준비물·변경 방법 | 노쇼·당일 변경 |
| 스레드 | 가이드에 따로 없음 → 위 말하는 방식 그대로, 첫 문장은 구체적 상황 | — |

- 네이버 대표 키워드(상호명 제외): 서면퍼스널컬러 · 전포퍼스널컬러 · 부산퍼스널컬러 · 서면메이크업 · 퍼스널컬러진단
- 인스타 해시태그 예: #서면퍼스널컬러 #부산퍼스널컬러 #퍼스널컬러진단 #메이크업컨설팅
- 가이드 캡션 예: "같은 코랄인데 왜 나만 얼굴이 칙칙해 보일까요? / 원인은 색 이름이 아니라 명도와 채도 차이예요. … / 나중에 립 고를 때 보려면 저장해 두세요."
- 상담 멘트 예: "오늘은 고객님이 원래 가진 색을 찾는 시간이에요. 바꾸는 게 아니라 찾는 거예요."
- 리뷰 답글: 리뷰 내용을 한 구절 언급하고, 다음 방문 이유를 하나.

## 7. 디자인 (디자이너 필수)
| 이름 | 값 | 쓰임 |
|---|---|---|
| Raw | #F5F5F4 | 기본 배경 (순백 대신) |
| Rough | #E6E4E7 | 카드·구분면 |
| White | #FFFFFF | 카드 면, 결과지 용지 |
| Line | #D6D2D8 | 구분선 |
| Slate | #6B6670 | 보조 글자·캡션 |
| Onyx | #221F26 | 본문·로고·선 (순검정 #000 금지) |
| Tourmaline | #7E4560 | **유일한 포인트 — 한 장에 한 곳만** (예약 안내, 강조 1곳) |
| Tourmaline Tint | #EFE4E9 | 강조 박스 배경 |
| Lilac | #D9D2E3 | Mist Light 전용, 단독 면 금지 |

- 비율: 바탕 70% · 구조(Onyx·Slate) 25% · 포인트 5%.
- 시그니처 **Mist Light** 하나: `radial-gradient(120% 140% at 75% 30%, #EFE4E9 0%, #D9D2E3 40%, #F5F5F4 85%)`. 인스타 커버·피드·후기·감성 문구 카드에만. 진하게 올리거나 다른 색 섞지 않음. 위 글자는 Onyx. 첫인상(명함·간판·웹 첫 화면)은 단색.
- 대비: Slate는 Rough 위에서 18px 이상(또는 굵은 14px 이상)만, Lilac 위에서는 본문 금지 → Onyx.
- 서체(모두 OFL): 워드마크·영문 헤드 **Tenor Sans**(자간 +200~340) / 국문 헤드 **Hahmlet** Light·Regular(자간 −2%) / 본문 **Pretendard**(행간 170%, 없으면 IBM Plex Sans KR).
- 모서리 거의 없음(기본 0, 큰 면 2px, 키워드 칩만 둥글게). 그림자 대신 헤어라인(Line)과 Onyx 1px 윗선.
- 로고: RIAN 워드마크 하나, 심볼 없음. 자간 0.34em, 사방 'R' 높이 여백, 화면 최소 72px. 밝은 배경 Onyx, 어두운 배경 Raw.
- **금지:** 보석·다이아몬드 아이콘, 반짝이(✦)·글리터·광택, 골드·로즈골드 메탈릭, 얼굴 위 로고, 가이드에 없는 색·서체·그라데이션.
- 아이콘: 가는 선, Slate 단색. 목록 기호는 Tourmaline 1.4px 테두리 작은 마름모.
- 인스타 카드 크기 예: 1080×1350(4:5). 기존 예: '위치 및 주차 안내' 3장(첫 장 Mist Light, 나머지 Raw).

## 8. 사진
- 자연광 또는 5000~6500K. 비포·애프터는 같은 조명·각도·거리.
- 배경 무채색. **필터 금지**(색이 상품인 업종). 보정은 잡티 정리까지만, 피부색·얼굴형 변경 금지.
- 고객 얼굴은 서면 동의 받은 것만, 동의서에 쓸 곳(SNS·플레이스·광고) 명시.
- 결과지·진단 그림은 고객 색 칩만 유채색.

## 9. 아직 하지 않는 것
- **이미지 컨설팅**은 실제 메뉴가 없으므로 어떤 글·광고에도 표기하지 않는다.
