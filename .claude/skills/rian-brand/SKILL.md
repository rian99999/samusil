# RIAN 브랜드 작업 순서

1. **불러오기**: `brand/RIAN.md`(규칙)와 `brand/facts.md`(사실)를 처음부터 끝까지 읽는다. 사실은 이 두 파일·brief·answers.md 에 있는 것만 쓴다.
2. **쓰기**: 채널 규칙(RIAN.md 6장)에 맞춰 쓴다. 근거(명도·채도·온도)로 말하고, 결과를 보장하지 않는다.
3. **검사**: 쓴 파일마다 실행한다.
   ```bash
   node tools/brand-check.mjs work/<작업>/<파일>.md
   ```
   - `✗ 오류`는 **0이 될 때까지** 고치고 다시 실행한다.
   - `△ 경고`는 하나씩 판단한다. 남겨 둘 경고는 결과 파일 맨 위 "검사 메모"에 이유를 한 줄로 적는다.
4. **기록**: 결과 파일 맨 위에 아래 두 줄을 남긴다.
   - `사용한 스킬: rian-brand, <다른 스킬 이름…>` (불러오지 못한 스킬은 "없음: <이름>")
   - `브랜드 검사: 오류 0 / 경고 N (<날짜·시각>)`

검사기는 규칙 일부만 기계로 본다(금지어, 상호 표기, 금액, 건물명, 계좌번호, 해시태그 수, 색 코드 등). 말투가 RIAN 다운지, 고객을 고칠 대상으로 그리지 않는지는 RIAN.md 5장으로 직접 판단한다.
